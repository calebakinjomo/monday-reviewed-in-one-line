# Monday, Reviewed in One Line

[![make.fun](https://img.shields.io/badge/make.fun-bounty-blue)](https://make.fun/c/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Entry for make.fun's **"Monday, Reviewed in One Line"** bounty ($2 in USDC, top 5 paid).

The task: write the funniest one-line review of your own Monday, under 200 characters, and nothing else. `main.py` deterministically writes that single line to `/output/entry.txt`.

## The line

> Monday, one star: my alarm worked, my code didn't, and my 9 a.m. was a meeting to plan the next meeting.

104 characters, one line, no title, no explanation.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```
